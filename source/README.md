# Source

[unit-index.json](unit-index.json) preserves the 1,979 stable source IDs, act/scene/speaker metadata and exact normalized text hashes. It contains metadata, while [provenance.json](provenance.json) links the historical text. [Chapter coverage](../adaptation/source-coverage.json) assigns each ID once across the twelve frozen chapters.

Historical Cambridge Volume II (1863), Clark/Wright, is the source edition. The repository initially provides provenance and an external historical-text link; it does not redistribute the downloaded ebook container or its editorial apparatus. See provenance.json and ../licensing/source-rights.md.
